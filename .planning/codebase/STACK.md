## Database / ORM

- PostgreSQL (Supabase-hosted, pooler `aws-*.pooler.supabase.com:6543`).
- Prisma 7.4.2 with the `@prisma/adapter-pg` driver adapter (not the legacy binary engine). Connection string read from `DATABASE_URL`; migration tooling uses `DIRECT_URL` (see `.env.example`).
- Schema at `prisma/schema.prisma` (provider `postgresql`). Generated client emitted to `src/generated/prisma/` and imported in `src/lib/db.ts`.
- `prisma.config.ts` defines schema path, migrations dir, and pulls `DATABASE_URL` from env via `dotenv/config`.
- Models: `Account`, `Statement`, `Category`, `CategorizationRule`, `Transaction`, `Subscription`, `Settings`, `ChatSession`, `ChatMessage`. Enums: `AccountType`, `TransactionType`, `BillingCycle`.

## Configuration

**Environment:**
- `.env.example` documents `DATABASE_URL`, `DIRECT_URL`, `GEMINI_API_KEY`, `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`. `SUPABASE_SERVICE_ROLE_KEY` is read at runtime in `src/app/api/statements/upload/route.ts` and in the GitHub Action `supabase-keepalive.yml` but is not listed in `.env.example`.
- Settings (Gemini API key + chat model) also persisted in the `Settings` table (`id: "default"`) and read via `prisma.settings.findUnique` at request time.

**Build:**
- `next.config.ts` - declares `allowedDevOrigins: ["192.168.56.1"]` and custom headers for `/sw.js` (no-cache, `Service-Worker-Allowed: /`) and `/manifest.webmanifest`.
- `tsconfig.json` - strict TypeScript, `jsx: react-jsx`, path alias `@/* → ./src/*`.
- `postcss.config.mjs` - registers `@tailwindcss/postcss` plugin.
- `eslint.config.mjs` - flat config with Next core-web-vitals + TS rulesets.
- `prisma.config.ts` - sets schema + migrations path, pulls `DATABASE_URL` from env.
- `middleware.ts` - Supabase SSR auth gate matched on `/api/:path*`; rejects unauthenticated requests with HTTP 401.

## Platform Requirements

**Development:**
- Node.js (>= 20 recommended per `@types/node` ^20).
- npm.
- Network access to a Supabase Postgres instance (no local SQLite fallback; `src/lib/db.ts` throws if `DATABASE_URL` is missing).
- Optional: Google Gemini API key for PDF parsing / chat / AI categorization.

**Production:**
- Deployment target: Vercel (PWA setup committed; `commit 63929a5: Add PWA setup for Vercel deployment`). `public/sw.js` and `public/manifest.webmanifest` served with explicit headers from `next.config.ts`.
- Supabase Postgres pooler (port 6543, `pgbouncer=true`, `connection_limit=1`) for runtime.
- Supabase Storage bucket `statements` for uploaded CSV/PDF files (see `STORAGE_SETUP.md`, `scripts/create-bucket-via-api.js`).
- Self-hosted Supabase Docker option provided (`docker-compose.supabase.yml`, `SELF_HOSTED.md`).
- GitHub Actions: `.github/workflows/supabase-keepalive.yml` pings the Supabase REST API every 6 hours to keep the free-tier project warm.
